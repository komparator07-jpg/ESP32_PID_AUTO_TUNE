# ESP32 Water Heater PID Controller with Auto-Tuning & NVS

Модуль терморегулирования для ESP32 с использованием NTC-термистора, управления нагревателем через SSR (с привязкой к частоте питающей сети), адаптивной автокалибровкой (Autotuning) для различных уставок и энергонезависимым сохранением коэффициентов в NVS (Preferences).

---

## 📌 Ключевые возможности

* **Адаптивный ПИД-регулятор:** Дифференцирование по измерению (без прыжков при смене уставки), защита от насыщения интегратора (Anti-windup) и фильтрация D-составляющей.
* **Автокалибровка (Relay Feedback / Tyreus-Luyben):** Автоматический подбор $K_p, T_i, T_d$ и базового смещения мощности ($bias$) последовательно для 4 уставок температуры.
* **Сохранение в NVS:** Результаты калибровки автоматически сохраняются во флеш-память ESP32 (`Preferences`).
* **Мягкая коммутация SSR:** Квантование мощности по целочисленным полупериодам сети (50/60 Гц) без сетевых помех.
* **Многоступенчатая фильтрация NTC:** Усреднение АЦП + медианный фильтр (3 отсчёта) + экспоненциальное сглаживание (EMA).
* **Безопасность:** Автоматическое отключение нагрева при обрыве/замыкании термистора или превышении таймаутов.

## ⚙️ Настройки и конфигурация (`#define`)

Все базовые настройки задаются в начале файла в блоке `НАСТРОЙКИ`.

### 1. Пины и управление нагревателем
| Параметр | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `NTC_PIN` | `34` | Пин АЦП для термистора. **Используйте только ADC1 (GPIO 32–39)**, так как ADC2 конфликтует с Wi-Fi. |
| `HEATER_PIN` | `25` | Пин управления силовой частью (SSR / ТЭН). |
| `HEATER_ACTIVE_HIGH` | `1` | `1` — активный уровень High (3.3В = ВКЛ), `0` — Low. |
| `HEATER_DRIVE_BUILTIN` | `1` | `1` — модуль сам коммутирует пин по полупериодам сети, `0` — вы даёте только % мощности (`pidOutput`), а коммутацией занимается внешний код. |
| `MAINS_HZ` | `50` | Частота питающей сети (50 или 60 Гц). Используется для квантования периода SSR. |

### 2. Параметры NTC-термистора
| Параметр | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `NTC_R0` | `100000.0f` | Сопротивление термистора при 25 °C (100 кОм). |
| `NTC_T0_C` | `25.0f` | Базовая температура для `NTC_R0` (°C). |
| `NTC_BETA` | `3950.0f` | Бета-коэффициент термистора ($B$-constant). |
| `R_FIXED` | `100000.0f` | Сопротивление постоянного резистора в делителе напряжений (Ом). |
| `NTC_TO_GND` | `1` | Схема делителя: `1` — `3V3 -> R_FIXED -> (ADC) -> NTC -> GND`<br>`0` — `3V3 -> NTC -> (ADC) -> R_FIXED -> GND` |
| `ADC_VCC_MV` | `3300.0f` | Напряжение питания делителя в милливольтах (3300 мВ). |
| `TEMP_OFFSET_C` | `0.0f` | Калибровка/смещение температуры (°C). |

### 3. Уставки и ПИД-параметры
| Параметр / Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `SETPOINTS[4]` | `{40.0f, 50.0f, 60.0f, 70.0f}` | Массив из 4 целевых температур (°C). |
| `PID_PERIOD_MS` | `200` | Интервал перерасчёта ПИД-алгоритма (мс). |
| `TEMP_SAMPLE_MS` | `20` | Интервал опроса термистора (мс). |
| `TEMP_EMA_ALPHA` | `0.15f` | Коэффициент EMA-фильтра температуры (0.01..1.0). Меньше = плавно, больше = быстро. |
| `D_FILTER_N` | `8.0f` | Коэффициент фильтрации дифференциальной компоненты ($T_f = T_d / N$). |
| `DEF_KP`, `DEF_TI`, `DEF_TD` | `5.0f`, `60.0f`, `5.0f` | Дефолтные коэффициенты ПИД (до выполнения калибровки). |

### 4. Автокалибровка (Autotune)
| Параметр | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `AT_OUT_MAX` | `100.0f` | Максимальная мощность, подаваемая при калибровке (%). |
| `AT_NOISE_BAND_C` | `0.3f` | Гистерезис (ширина полосы шума) при переключении реле (°C). |
| `AT_MIN_HALF_MS` | `3000UL` | Минимальное время полупериода раскачки (защита от ложных срабатываний). |
| `AT_HALF_TIMEOUT_MS`| `600000UL` | Таймаут полупериода (10 минут). Если температура не пересекает уставку за это время — выдается ошибка. |
| `AT_RULE` | `0` | Метод расчёта ПИД:<br>`0` — Tyreus-Luyben (плавный, минимум перерегулирования)<br>`1` — Ziegler-Nichols (агрессивный)<br>`2` — Небольшое перерегулирование<br>`3` — Без перерегулирования (вялый) |
| `AT_KP_SCALE` | `1.0f` | Общий множитель коэффициента $K_p$ (корректировка жесткости регулятора). |

## 🔄 Глобальные переменные системы

Эти переменные вы можете читать или изменять во внешнем коде вашего приложения:

* `float pidTemp` — сглаженная текущая температура (°C).
* `float pidSetpoint` — текущая выбранная уставка (°C).
* `int pidSpIndex` — индекс активной уставки (0..3).
* `float pidOutput` — текущий выход ПИД / требуемая относительная мощность ТЭНа (от `0.0` до `100.0` %).
* `float pidFeedforward` — внешняя добавка мощности в % (например, коррекция при изменении протока воды).
* `float pidGainScale` — динамический множитель усиления (по умолчанию `1.0f`).
* `bool pidSensorOk` — статус датчика температуры (`true` = данные корректны, `false` = обрыв/сбой).
* `PidMode pidMode` — режим работы регулятора (`PID_OFF`, `PID_RUN`, `PID_AUTOTUNE`).
* `AtState atState` — статус автокалибровки (`AT_IDLE`, `AT_RUNNING`, `AT_DONE`, `AT_FAILED`).

## 🛠 Руководство по настройке и запуск

### 1. Первый запуск и калибровка
1. Загрузите код в ESP32 и откройте Serial Monitor на скорости **115200 baud**.
2. В консоли отобразится предупреждение:  
   `Калибровки нет: отправьте 'a' для автокалибровки`
3. Отправьте символ **`a`** в монитор порта для запуска автокалибровки.
4. Процесс пройдет последовательно по всем 4 уставкам (40, 50, 60 и 70 °C). По завершении коэффициенты автоматически запишутся в NVS (флеш-память).

### 2. Управление через Serial (команды)
| Команда | Действие |
| :---: | :--- |
| `1` .. `4` | Выбор уставки 0..3 (40 °C, 50 °C, 60 °C или 70 °C). |
| `g` | Запуск регулирования (`PID_RUN`). |
| `s` | Остановка нагрева (`PID_OFF`). |
| `a` | Запуск полного цикла автокалибровки. |
| `x` | Прерывание процесса автокалибровки. |

## 🔌 API функции для интеграции в код

```cpp

void pidUpdate();             // Вызывать в loop() как можно чаще (без delay)

void pidAutotuneAbort();      // Прервать автокалибровку

bool pidLoadCalibration();    // Загрузить коэффициенты из NVS
void pidSaveCalibration();    // Сохранить текущие коэффициенты в NVS
void pidClearCalibration();   // Очистить сохраненные данные в NVS
